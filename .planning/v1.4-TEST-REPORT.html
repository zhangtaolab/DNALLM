12.词汇表

测试通道（lane）
按目录划分的一组测试，如"tests/mcp"专测 MCP 服务器。
覆盖率（coverage）
测试实际执行到的代码行占比。90% 硬门槛意味着低于 90% 时 CI 自动失败，防止测试被悄悄删减。
回归测试（regression）
把旧功能的测试重跑一遍，确认新改动没有弄坏旧东西。
must-have / 验收条款
计划阶段写下的"必须为真的事实"，完成时逐条对照真实代码核验，不是自我报告。
威胁建模（threat modeling）
提前枚举"可能怎么出事"（数据被改、信息泄漏、恶意输入等），再逐条确认防护真实存在。
slow / 夜间测试
耗时长（真实下载模型、GPU 推理）的测试，放在夜间通道跑，日常提交不等待它们。
技术债（tech debt）
已知但暂不处理的改进项，全部有记录、有理由、可追踪。
MCP
Model Context Protocol——让大语言模型代理直接调用本工具包能力的标准协议。
注册表（registry）
内置的 236 个 DNA 模型目录（model_info.yaml），记录每个模型的仓库地址、任务类型、标签等；本里程碑后它是全链路唯一事实来源。
