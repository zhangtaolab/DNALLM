# Quick Task 261026-b34: Per-lane workflow_dispatch selection for nightly lanes — Summary

Added per-lane manual-dispatch selection to the three nightly lanes in ci.yml:
three `type: boolean` workflow_dispatch inputs (all `default: true`), each
nightly job's dispatch arm ANDed with its own input, so a dispatch can fire one
lane instead of all three (~6h queue-serialized on the single dnallm-nightly
runner; the REST API cancels runs, not jobs, so a misaimed dispatch could not
be trimmed after the fact — run 40246863966). No-flag dispatch behavior is
byte-compat with the old all-lanes dispatch.
