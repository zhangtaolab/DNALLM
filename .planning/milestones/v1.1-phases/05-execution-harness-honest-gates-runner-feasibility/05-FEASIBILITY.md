## marimo execution-flavor decision (Phase 8 standard)

**export-html** — `marimo export html <app>.py -o <tmp>/out.html` gives a deterministic exit code AND a concrete artifact (HTML with the executed outputs) per app, on a warm cache in ~40s. Script-mode (`python <app>.py`) also terminates deterministically (~10s) and binds no port, so it remains an acceptable fallback flavor; the spike recorded both exit codes, wall times, port sampling (none bound), and the artifact size.
