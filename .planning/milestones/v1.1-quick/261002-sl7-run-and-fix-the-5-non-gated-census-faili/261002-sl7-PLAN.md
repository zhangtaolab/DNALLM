1. **benchmark.ipynb** — KeyError `Column labels not in the dataset. Current
   columns: ['sequence']` at `dnallm/inference/benchmark.py:296`. ROOT CAUSE
   (reproduced live): the harness sandbox seeds only the notebook's parent dir
   (`tmp_path/benchmark/`), so `benchmark_config.yaml`'s `path:
   ../inference/test.csv` resolves to a missing file;
   `DNAInference.generate_dataset` then silently treats the path STRING as a
   single sequence (`sequences = [seq_or_path]`), building a one-row dataset
   whose only column is `sequence`. The AttributeError the user hit earlier on
   this notebook is already fixed by fdc4915.
2. **finetune_data.ipynb** — `TypeError: 'dict' object is not an instance of
   'Sequence' while processing 'vocab'` at cell 10
   (`AutoTokenizer.from_pretrained("zhangtaolab/plant-dnabert-BPE")`),
   reproduced live: transformers 5.17 passes `vocab` as an insertion-ordered
   dict `{token: score}` into `DebertaV2Tokenizer.__init__`, whose 5.x body only
   handles None/list (4.x accepted dicts). Cells 14-15 additionally reference
   `../../../../tests/test_data/regression/*.csv`, unreachable from the sandbox.
3. **embedding_attention.ipynb** — `ImportError: cannot import name
   'find_pruneable_heads_and_indices' from 'transformers.pytorch_utils'`. The
   notebook NEVER imports dnallm (cells verified), so the existing
   `_patch_remote_code_pruning_helpers` shim is inert in its kernel. After
   activation, the same remote code also reads `config.is_decoder` (remote
   modeling_esm.py:335) → needs Task 1a; `get_extended_attention_mask` is
   already covered by fdc4915.
4. **finetune_NER_task.ipynb** — `ValueError: Failed to load model: 'EsmConfig'
   object has no attribute 'is_decoder'` (remote modeling_esm.py:335/584-585
   read `config.is_decoder` and `config.add_cross_attention` at model build;
   transformers 5.17 PretrainedConfig has no `__getattr__` and no class-level
   defaults — verified live).
5. **finetune_generation.ipynb** — `FileExistsError` from pyfastx (its
   missing-file quirk): `Arabidopsis_thaliana.TAIR10.cds.all.fa.gz` is not
   present; cell 1 already carries the commented pinned download URL. Second
   half needs the megaDNA package (see scope decision).
6. **inference_for_tRNA/inference.ipynb** — `ImportError: cannot import name
   'MambaCache' from 'transformers.cache_utils'` (tRNADetector remote
   modeling_mamba.py:27, constructed with the 4.x signature
   `MambaCache(config, batch_size, device=..., dtype=...)` at its line 670);
   verified live that MambaCache exists nowhere in transformers 5.17.
