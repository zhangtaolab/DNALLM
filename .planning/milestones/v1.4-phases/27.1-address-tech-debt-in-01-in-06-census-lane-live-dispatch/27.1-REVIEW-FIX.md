### CR-01: IN-05 skip branch drops `$GITHUB_PATH`, so the next step's `uv venv` may not find `uv`

**Files modified:** `.github/workflows/census_compat.yml`, `tests/test_runner_infra_contracts.py`
**Commit:** 76ea80f (`fix(27.1-02): write provisioned uv to GITHUB_PATH in the census skip branch`, pushed to `origin v1.4`)

**Applied fix:** In the census lane's `Install uv` step, the IN-05 skip
branch now persists the provisioned uv's install directory across steps by
appending it to `$GITHUB_PATH` (`echo "$HOME/.local/bin" >> "$GITHUB_PATH"`,
with a two-line comment recording why: the curl installer the guard replaces
performed exactly this write, and every later step calls bare `uv`). The
step-local `export PATH="$HOME/.local/bin:$PATH"` and the
`uv --version` echo are kept unchanged, and the wiped-box `curl | sh`
fallback in the else branch is untouched (that branch gets its
`$GITHUB_PATH` write from the installer itself). This restores the
cross-step propagation that `ci.yml`, `docs-validation.yml`, and
`feasibility.yml` all rely on, so the next step's bare `uv venv` /
`uv pip install` resolves uv on the provisioned box instead of failing with
`uv: command not found` and reddening the single allowed DISP-01 dispatch
for an environment reason.

The offline pin `TestCensusLaneInstallSequence.test_uv_install_skips_provisioned_binary`
was extended (no existing assertion weakened or deleted) with:

- a new constant `CENSUS_UV_GITHUB_PATH_WRITE` and an assertion that the
  skip branch carries the exact `echo "$HOME/.local/bin" >> "$GITHUB_PATH"`
  line;
- an ordering assertion that the write sits INSIDE the skip branch
  (`command -v uv` < write < installer pipeline), so moving it out of the
  branch or reverting it editorially fails the fast lane in seconds.

The pre-existing assertions for the single-`Install uv`-step count, the GPU
`if:` guard, the step-local PATH export, the `command -v uv` probe, the
`$(uv --version)` echo, the guard-before-curl ordering, and the
no-`UV_VERSION` rule all still hold and still run (14/14 tests green).
