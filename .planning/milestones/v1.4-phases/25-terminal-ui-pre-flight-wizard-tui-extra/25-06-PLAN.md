## Objective

Deliver the second wizard step: a data panel that hands a user-supplied path to `validate_data` through the worker seam and renders the returned `DataReport` — split row counts, length statistics, charset census, and every finding with severity, reason code, and count — plus the D-08 skip path that keeps the wizard usable without data.

Purpose: TUI-04 is the user's first contact with their own data; the panel must be a faithful renderer of the Phase-23 report and nothing more.

Output: `dnallm/tui/screens/data.py`, extended app routing, copy constants, and screen tests.

## Locked in-plan decisions

- **One path input + one action.** The panel offers a text path field and a "Check this data" button; the file dialog is out of scope (no new dependency).
- **Skip is a first-class action** (D-08): it advances with `data_report=None` and states the consequence in plain language.
- **Error rendering:** a core report carrying an error finding (READ_ERROR, UNSUPPORTED_FORMAT_PKL, SEQUENCE_COLUMN_NOT_FOUND) is rendered like any other finding — the screen never inspects the exception, because none is raised.
- **Findings order is the core's order.** No sort, no filter, no grouping beyond a table column.

| T-25-10 | Tampering | crafted/untrusted data file | high | mitigate | The screen never opens the file; `validate_data` refuses pickle paths and reports unsupported formats as findings; all rendered values pass through the markup-disabled helper. |
| T-25-11 | Denial of service | very large data file in a worker | low | accept | The read runs in a thread worker so the UI stays responsive; the app's quit path cancels the worker; per-test timeout caps a hung read at 300 s. |
