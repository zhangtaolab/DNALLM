## Pattern Assignments

### New rungs in `dnallm/utils/transformers_compat.py` (shim)

**Analog A — version/absence-gated rung (GENERanno ROPE):** `_patch_apply_chunking_to_forward` (lines 1534-1556) and the module-attach helper (lines 1515-1531). Three-step shape:

```python
def _patch_apply_chunking_to_forward():
    try:
        import transformers.modeling_utils
        import transformers.pytorch_utils
    except Exception:  # pragma: no cover - transformers not installed / module renamed
        return
    _attach_apply_chunking_to_forward(transformers.modeling_utils, transformers.pytorch_utils)
```
Import guard → per-name absence gate → install → module sentinel (`_dnallm_apply_chunking_patch = True` via `setattr`, lines 1526-1530) for idempotency. For the ROPE rung, mutate the live dict in place — `ROPE_INIT_FUNCTIONS.setdefault("default", _compute_default_rope_parameters)` — never reassign (remote modules hold a bound reference). The sentinel here is dict membership itself. Vendored implementation convention: verbatim 4.x code with cited version and deviation notes (docstring style of lines 1535-1549).

**Analog B — load-boundary wrapper rung (GENA-LM buffer, MutBERT forward):** `_patch_tied_weights_bookkeeping_on_load` (lines 1604-1688) with `_materialize_tied_weights_bookkeeping` (1584-1601) and module-level `_tied_bookkeeping_original_finalize` (1581). Shape: probe gate (`_post_init_computes_tied_weights_keys()`) + class sentinel (`_dnallm_tied_bookkeeping_patch`) + captured original kept module-level; the wrapper runs at `_finalize_model_loading`, which transformers 5.17 calls after weight loading — the verified seam for both post-load repairs. Add per-instance defect detection: GENA-LM = buffer values outside `[0, type_vocab_size)`; MutBERT = `"input_ids.size()[:-1]" in inspect.getsource(cls.forward)` wrapped in `try/except (OSError, TypeError)` (treat unreadable source as "no defect"). Reset value is `torch.zeros(position_ids.size(), dtype=torch.long)` — NOT `torch.arange(type_vocab_size)` (measured: IndexError at `modeling_bert.py:1238`).

**Registration:** append installers to `apply_patches()` (lines 1699-1712; device-type-query rung must stay FIRST) and to `EXPECTED_PATCH_INSTALLERS` (`tests/utils/test_transformers_compat.py:1343-1359`) plus `test_apply_patches_stays_idempotent_with_new_rungs` (`tests/utils/test_transformers_compat_census.py:487-498`).

## Shared Patterns

### Rung discipline (applies to all three new rungs + DNABERT-2 installer)
**Source:** `dnallm/utils/transformers_compat.py` Rungs 12/13
Import guard → per-name/probe/absence gate → install → sentinel idempotency → no-op when target absent. Hybrid guard policy (D-08): version/absence gates for tf5 classes (ROPE, DNABERT-2); defect-detection gates for author defects (GENA-LM value-range, MutBERT source-marker) so 4.x benefits too.

### Honest write-back (applies to registry flips, docs, tests)
Dispositions flip only via `--write-registry --apply` after a green re-probe; `SHIM_RESTORED_LOADS` (tool + test mirror) must be updated in the SAME commit; `DOCS_DATA_DATE` bumped with the re-census; the drift gate (`tests/models/test_compat_docs_consistency.py:288-337` — footnotes verbatim and ordered under the table, forbidden-claim check, summary sentence re-derived from live registry counts) re-pins automatically. Page tail is not pinned: the one-line D-14 link is gate-safe.

### Test independence
Gates re-derive expectations from committed artifacts/registry and keep literal copies of wordings — never import the writer's mapping (`test_compat_docs_consistency.py:312-337`, `test_model_info_registry.py:445-488` docstrings state the discipline).

### UI safety gate
`dnallm/tui/` counts as frontend (`.planning/config.json` `ui_safety_gate: true`) — a UI-SPEC or an explicit "one column of plain words, no new UI surface" justification is required before the TUI plan closes.
