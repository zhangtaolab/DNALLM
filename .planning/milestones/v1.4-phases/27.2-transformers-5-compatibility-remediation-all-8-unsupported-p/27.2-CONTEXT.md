<domain>
## Phase Boundary

Restore transformers-5 usability for every fixable preset among the 8 census-non-green entries (7 `remote-code-broken` + 1 `census-blocked`) and ship the support story across docs/README/TUI/MCP. Concretely: four compat-rung code fixes (GENERanno, DNABERT-2, GENA-LM, MutBERT), two install-guidance message upgrades (GPN, Omni-DNA), two documentation alignments (GENA-LM-BigBird deepspeed, CrossDNA census-route alignment), and the support surface (regenerated `model_compatibility.md`, a new plain-language optional-dependency docs page, a README supported-models statement, TUI/MCP listing support flags, and test/census-lane pin updates).

Census discipline is inherited unchanged from Phase 27: a disposition flips ONLY on a measured green probe re-run (replica-grade until the census lane is live post-merge); repaired models are always worded "works with DNALLM's built-in compatibility fixes", never "as-is". The lgq12697 bulk-ingestion backlog (~130 unregistered entries) is explicitly OUT of scope (separate v1.5 campaign).

</domain>

<decisions>
## Implementation Decisions

### Campaign Scope & Discipline (owner rulings 2026-10-29, folded from todo)

- **D-01: All 8 items fixed inside v1.4; the v1.4→main merge is deferred by design until this phase lands.** Scope explicitly includes the two "fix-on-behalf-of-authors" items (GENA-LM buffer reset, MutBERT forward wrap) despite the tension with honest-census discipline — the resolution is measured-first dispositions plus explicit repair wording.
- **D-02: Measured-first disposition flips (Phase 27 D-06 inherited).** Each item ships code + tests in the same change; its `tf_compat_status` flips ONLY after a measured green probe re-run (single-entry census re-probe, replica-grade evidence until the census lane is live post-merge). No fix is claimed green without the probe.
- **D-03: Disposition value and wording for repaired models follow Phase 27-03 precedent.** Repaired entries whose green load depends on a rung get `shim-required-tf5` (verdict + rung dependency, never a "works natively" claim); the public page states "works with DNALLM's built-in compatibility fixes (tested)". GPN/Omni-DNA (install-guidance) and GENA-LM-BigBird (document-only) keep their honest broken/unusable dispositions with better guidance, NOT fake-green flips.

### Compat Rung Fixes (todo Plan A)

- **D-04: GENERanno — register a `'default'` ROPE init alias** into the remote `GenerannoRotaryEmbedding` ROPE_INIT_FUNCTIONS dicts at the load boundary (`dnallm/utils/transformers_compat.py`), per-name absence-gated, tf5-triggered. First measured appearance of the ROPE failure class Phase 27 research predicted; evidence pinned at ms commit `0ae1f40f`.
- **D-05: DNABERT-2 — wrap remote `rebuild_alibi_tensor` for device alignment** (both tensors constructed on the same device), extending `dnallm/models/special/dnabert2.py`. Owner rejected the force-CPU-construction alternative: only the one measured-broken operator is fixed and meta-device fast/low-memory init is preserved. (tf5-construction-path-triggered.)
- **D-06: GENA-LM — post-load reset of the corrupted `bert.embeddings.token_type_ids` buffer** to `torch.arange(type_vocab_size)`, restoring exact constructor-intended semantics; documented prominently as a dnallm repair of a checkpoint data defect (persisted value 3901475131392 vs `type_vocab_size=2`; broken on every transformers version). Owner-approved author-defect repair.
- **D-07: MutBERT — wrap the remote forward to correct `input_shape` to `input_ids.shape`** (authors' own `# modified` line at `modeling_mutbert.py:808` drops the sequence dim for every 2-D input; fails identically on 4.x). Documented as an author-bug repair. Owner-approved.
- **D-08: Hybrid guard policy.** tf5-removal/construction-path classes (GENERanno, DNABERT-2) use version/absence gating per Phase 27 rung convention; version-independent author defects (GENA-LM buffer, MutBERT forward) use defect-detection guards (repair whenever the defect is detected, any transformers version) so 4.x users benefit too. All rungs stay probe-gated, per-name absence-gated, idempotent via sentinels, no-op when target absent.
- **D-09: Two-layer evidence for data repairs.** Offline pytest assertions on the repaired state (e.g. GENA-LM buffer value/shape after reset — network-free) PLUS the D-06 measured green probe for the disposition flip. The pytest layer catches upstream checkpoint swaps without waiting for the next census.

### Install Guidance & CrossDNA Reporting (todo Plan B)

- **D-10: GPN / Omni-DNA — upgrade ImportError messages to exact pip-install lines** (`pip install gpn` / the olmo package line) and point to the new docs section; handlers unchanged, no new dependencies (gpn/olmo stay external).
- **D-11: GENA-LM-BigBird — document-only.** State the external `deepspeed` requirement and why it is deliberately NOT a dependency and NOT stubbable (stub = silently wrong block-sparse attention math).
- **D-12: CrossDNA — teach the census tool subdirectory navigation.** `scripts/census_compat.py` resolves CrossDNA configs the way `special/crossdna.py` does, with the handler's `_PREFERRED_CHECKPOINT_DIRS` as the single source (import or test-pinned mirror — implementer's choice); CrossDNA is then re-measured to a REAL verdict instead of `census-blocked`. The public page stops implying the model is unusable when dnallm loads it fine. — **Reversibility:** reversible — a tool change, but it deliberately changes the census口径 for future re-runs (any later repo with checkpoint subdirs gets measured through the same route).

### Docs / Support Surface (todo Plan C)
