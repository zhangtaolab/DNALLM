<objective>
Evidence-only spike proving (or refuting) that a zero-dependency numpy left-outer-join interval intersect matches `bedtools intersect -loj` (v2.31.1) row-for-row, order-for-order, null-for-null — de-risking windows-ledger id 19's NER half: Windows replaces `BedTool(tokens_bed).intersect(annotation_bed, loj=True)` with this implementation while Linux keeps pybedtools.

Purpose: jaccard parity (quick 261010-wx2, VERDICT: PARITY) does NOT transfer to join semantics — loj is a JOIN, not a merge: every A row survives, B rows multiply per overlap, null-B rows carry a specific bedtools null encoding, and the NER consumer traverses the result relying on ascending order. Without this parity the platform-split would be two truths; this spike produces the deciding evidence without touching any production code.

Output: A deterministic, seeded, re-runnable spike script (task artifact, never library code), a captured report (report.txt) with the three empirical pins and the mismatch inventory, and a SUMMARY with the verdict and the #19 NER-port implications paragraph.
