## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Monitor `gh --jq -r` flag order | `-r` after `--jq` is swallowed as the jq program value; gh fails every poll with stderr discarded → 30 min of silent blindness while CI actually finished | advisory | Inline-test the exact `gh` command (including jq expression) in a foreground Bash call BEFORE arming a Monitor; a Monitor that has emitted zero events by its first expected poll interval is defective, re-check manually |
| Squash-merge ancestry severance | PR #45 was squash-merged (single parent), so `git merge-base dev revision` falls back to the old dev lineage; the second merge conflicted on 4 files despite revision being a strict content superset | advisory | Use GitHub "Create a merge commit" for revision→dev PRs (or merge locally). When a phantom conflict appears: verify dev side contributed nothing, `git checkout --theirs` every UU path, and require `git diff --cached <revision-tip>` to be EMPTY before committing the merge — that emptiness is the proof nothing was lost. Saved as project memory `squash-merge-breaks-revision-dev-ancestry` |
