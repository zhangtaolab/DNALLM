Verified domain facts (06-RESEARCH.md Pattern 4/6):
- pyfastx 2.3.1 `fa.fetch('Chr1', (10, 20))` returns 11 bases == seq[9:20] — 1-based
  inclusive, identical to GFF3 coordinates (probe-verified).
- TAIR10 GFF3: 197,160 CDS rows end column 9 with a trailing ';' after the Parent value;
  CDS rows carry comma-joined double Parents ("Parent=AT1G01010.1,AT1G01010.1-Protein;").
- PlantDHS + TAIR10 + the FASTA all natively use TAIR ChrN naming; the '1' <-> 'Chr1'
  direction exists for Ensembl-style user inputs. ChrC/ChrM pass through.
- Existing re-export block to extend: dnallm/utils/__init__.py lines 10-15
  (from .sequence import ...) plus the alphabetical __all__ list.
