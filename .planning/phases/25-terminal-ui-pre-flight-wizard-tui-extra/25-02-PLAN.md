## Objective

Land the second half of Phase 25's atomic first act: the `dnallm/tui/` package skeleton, the TUI-01 structure guards, and the single thread-worker seam that every later screen rides on — before any panel exists. The seam is production code: typed messages, a real core call executed in a worker, and a cancellable download wrapper whose sentinel demonstrably escapes `download_model`'s retry loop.

Purpose: TUI-01 requires the structure guards and the worker seam to exist before the first screen (25-05); TUI-07's concurrency guarantee is created here so the download screen only renders an already-proven mechanism.

Output: `dnallm/tui/{__init__,messages,workers}.py`, `tests/tui/{test_structure,test_workers}.py`.

## Locked in-plan decisions

- **Seam shape: typed messages, one idiom.** Research Flag 1 is resolved as `@work(thread=True, exit_on_error=False)` methods on a `PreflightWorkers` mixin, posting typed `textual.message.Message` payloads. `call_from_thread` is not used anywhere (no single-setter case requires it).
- **Cancel semantics: cooperative.** Textual thread workers cannot be interrupted; `Worker.is_cancelled` means "stop at the next check". The UI copy will say "Stopping — this download attempt will finish first" (25-09). The sentinel is `DownloadCancelled(BaseException)`; the wrapper checks `get_current_worker().cancelled_event.is_set()` before each attempt.
- **`download_model` is not modified.** The `downloader` parameter is the injection point (and the test hook).
- **`run_preflight` lives in `dnallm/tui/__init__.py`** and imports `.app` inside the function body; `.app` arrives in 25-05, so this plan defines the entry point without wiring a panel.
