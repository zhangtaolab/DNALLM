## Locked in-plan decisions

- **The allowlist is the contract, declared once:** `SCREEN_CORE_ALLOWLIST = {screens/env.py: {collect_versions, collect_device, collect_disk}, screens/data.py: {validate_data}, screens/suitability.py: {check_compatibility, local_availability, probe_availability}, screens/config.py: {generate_config, edit_config, render_yaml}, screens/download.py: {download_model}, screens/summary.py: set(), screens/entry.py: set()}`. Both directions are asserted.
- **The end-to-end test injects every seam** (collector, prober, downloader) so it never touches the network or torch; it runs at `size=(100, 40)` and asserts the final summary text.
- **Coverage is measured with the repo's proven plain-coverage form** (`coverage run` + `coverage report --fail-under=96`), not pytest-cov (known broken in the dev venv on numpy 2.5.3/py3.13; CI matrix unaffected).
