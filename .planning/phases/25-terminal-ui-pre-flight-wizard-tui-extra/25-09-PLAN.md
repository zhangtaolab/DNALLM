## Objective

Deliver the optional closing step (D-09): after the validated config is emitted, offer downloading the selected model with visible progress and cooperative cancel, then a summary listing where the model files landed and where the config was written. Skipping the download is always allowed.

Purpose: TUI-07 is the only step that touches the network from user intent; it must be honest about what cancel can and cannot do, and it must never freeze the interface.

Output: the download and summary screens, hub/progress plumbing in the seam, copy, and tests.

## Locked in-plan decisions

- **Cancel semantics are cooperative** (research Flag 2, assumption A2): the wrapper checks `cancelled_event` before each attempt and raises `DownloadCancelled(BaseException)`; the real `download_model` retry loop is bypassed by construction. Copy never promises interruption.
- **Single model, sequential, no queue** (D-09 + Out-of-Scope): the screen works on `WizardState.selected_entry` only.
- **Hub choice:** `availability.source_hub` when the report has one; otherwise ModelScope for `is_lab` entries (owner directive: ModelScope-first, lab-first), else Hugging Face. No cross-hub fallback inside the screen — `download_model`'s own retry policy applies, and the user can retry from the error state.
- **Progress:** bind a `tqdm_class` reporter when the resolved downloader's signature accepts it (Hugging Face), posting byte progress; otherwise attempt-level progress with elapsed time. Both are rendered by the same progress widget.

| Boundary | Description |
|----------|-------------|
| downloader -> filesystem | Model files land under hub cache roots; the returned path is displayed |
| user intent -> network | A download is the largest network action in the product |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-16 | Tampering | downloaded model path display | medium | mitigate | The screen renders the string returned by `download_model` verbatim and never constructs or joins a path; no allow_patterns are user-supplied; hub cache roots remain library-owned. |
| T-25-17 | Denial of service | unbounded retries / unresponsive UI | medium | mitigate | `max_try` stays core-owned (default 10); the download runs in a thread worker; cancellation is checked between attempts; quit calls `cancel_all()`; a failed run surfaces a plain-language retry instead of an auto-loop. |
