<discovered_constraint>
Plan-time discovery (live probe, 2026-10-20): `import dnallm.models.registry` pulls torch,
transformers, and datasets into `sys.modules` transitively — `dnallm/__init__.py` eagerly imports
every subpackage, and `dnallm/utils/__init__.py` imports `cuda_compat`/`transformers_compat`/`support`
(torch). Therefore "import-light preflight" is enforced at SOURCE level exactly as RESEARCH words the
structure obligation ("zero torch/transformers/datasets imports inside dnallm/preflight/ at module
level") — a sys.modules-level purity test is impossible without an unsanctioned root-facade refactor
(CONTEXT explicitly keeps preflight OUT of the root facade but does not authorize making the root
facade lazy; that is a Phase-25-owner call, recorded here for that phase). Preflight's own modules
must stay free of the heavy trio in their own source so the discipline is real where this phase
controls it.
</discovered_constraint>
