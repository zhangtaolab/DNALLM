# Phase 27.1 Plan 02: Address Tech Debt IN-04/IN-05 Summary

**Receiver-safe transformers load-boundary shim: kwargs `model`/`self` now wins over every positional shape (a class-shaped positional can no longer absorb model bookkeeping), and the census lane stops replacing the runner's mirror-configured uv with an unpinned installer on every dispatch.**

## Accomplishments

- **IN-04 closed.** `_finalize_model_loading` resolves its receiver from `kwargs` first (`model`, then `self`) and only falls back to the existing positional rule (`args[1]` when the original binds as a class/instance method, else `args[0]`). When no plausible receiver exists it delegates unchanged. Three new contract tests pin the kwargs-only call (materialization lands on the model, delegated kwargs identical), kwargs precedence over a class-shaped positional (the class gains no `all_tied_weights_keys`), and no-receiver delegation (neither compat helper runs).
- The classmethod-binding hazard from RESEARCH Pitfall 3 is now regression-tested: a class carrying the computation surface is passed positionally alongside `model=...`, and the test proves the class is not mutated.
- **IN-05 closed.** The census lane's `Install uv` step exports `$HOME/.local/bin`, probes `command -v uv`, echoes `uv --version` when the box already has it, and keeps `curl -LsSf https://astral.sh/uv/install.sh | sh` only in the wiped-box `else` branch. No `UV_VERSION` setting was introduced (refuted in research).
- An offline pin (`test_uv_install_skips_provisioned_binary`) holds the guard, its before-curl ordering, the GPU `if:` condition, and the absence of `UV_VERSION` — so editorial removal fails on the fast lane, not at the next four-hour dispatch.
- Every standing lane invariant re-verified unchanged: dispatch-only triggers, `permissions: contents: read`, `[self-hosted, dnallm-nightly]`, the `github.event_name == 'workflow_dispatch'` guard, the 240-minute timeout, both `mkdir -p census-artifacts` lines, and the sha256-pinned `install_mamba.sh` invocation.

## Decisions Made

- Kwargs receiver wins unconditionally; positional resolution is only the fallback. This is both the direct IN-04 fix and the classmethod-binding hardening the research found adjacent to it.
- No receiver ⇒ delegate unchanged with no helper call. Guarding on `receiver is not None` is what keeps unusual call shapes safe rather than crashing them.
- IN-05 uses skip-if-present (RESEARCH OQ-2) because the served astral installer embeds its version and exposes no `UV_VERSION` knob. Restated explicitly: **the wiped-box fallback `curl | sh` remains unpinned** — accepted residual supply-chain exposure (T-27.1-06) for a path that should only execute on a reprovisioned box.
- Task 2 kept the red-first discipline (separate `test` and `feat` commits) so the pin is proven discriminating rather than vacuously green.
